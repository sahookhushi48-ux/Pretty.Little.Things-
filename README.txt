# She knows 🌸🌙 — free website

A responsive pink Pinterest-inspired website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout and pink aesthetic
- `script.js` — working games, filters, captions, copy buttons and mood generator

## Preview on your computer
1. Extract this ZIP file.
2. Open the `she-knows-website` folder.
3. Double-click `index.html` to open it in Chrome.

An internet connection is needed for Google Fonts and the remote Unsplash photos.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com
2. Click the **+** icon, then **New repository**.
3. Name it `she-knows`.
4. Select **Public**, then click **Create repository**.
5. In the repository, choose **Add file → Upload files**.
6. Open the extracted `she-knows-website` folder and upload `index.html`, `style.css`, and `script.js` (upload the files themselves, not the outer folder).
7. Click **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a minute or two. Your site should appear at:
   `https://YOUR-GITHUB-USERNAME.github.io/she-knows/`

## Customize it
- Change headings, captions, game questions and pin descriptions in `index.html` or `script.js`.
- Replace the `src="https://images.unsplash.com/..."` image URLs in `index.html` with image URLs you have permission to use.
- Keep the homepage file named exactly `index.html`.

## Important
- GitHub Pages hosting is free for public repositories.
- This is a static website; it does not collect visitor submissions or store user accounts.
- Photos are loaded from Unsplash URLs and need an internet connection.
